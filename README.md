# Liliana Montiel

Senior Data Analyst integrating AI/ML into supply chain to cut stockouts, sharpen forecasts, and automate reporting.

I design data products that change operational outcomes — not just dashboards. That means demand forecasts that measurably beat the baseline, reporting pipelines that compress hours of manual work into a single command, and AI tools that let non-technical teammates get answers from data in plain English. I work where a better model shows up directly in service levels and working capital: demand planning, in-stock performance, and inventory for retail and grocery.

---

### What I work with

- Languages: Python, SQL
- Data / ML: pandas, NumPy, scikit-learn, LightGBM, time-series forecasting
- Analytics & reporting: Excel automation (xlsxwriter), matplotlib, dashboards (Streamlit/Plotly)
- Data modeling: star schemas, window functions, dimensional warehouses
- AI: LLM-powered analytics tooling, prompt design, safe "LLM-plans-code-executes" patterns
- Domain: supply chain, demand planning, in-stock / inventory, retail & grocery
